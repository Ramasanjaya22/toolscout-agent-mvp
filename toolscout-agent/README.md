# ToolScout Agent MVP

Mock-first autonomous procurement agent for AI services.

## Quickstart

```bash
bun install
bun run dev
bun run server
```

Frontend runs on Vite, backend on Express+Bun.

## Workflow
User Objective → Planning → SAP Discovery (mock) → Ace Execution (mock) → x402 Settlement (mock) → Scoring → SQLite Persistence → Procurement Report.
